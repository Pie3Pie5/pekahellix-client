# V0.1 — Pekahellix Client
- Première PWA publique Client distincte de Pekahellix OS.
- 6 questions miroir Communication externe + NPS + 2 questions libres.
- Accès par code public de campagne dans l'URL.
- Aucune authentification client.
- Aucune donnée nominative demandée.
- Stockage Supabase par organisation et campagne.
- Résultats Client réservés à l'administrateur via RPC sécurisée.
- Service Worker limité au même domaine, sans cache Supabase.
